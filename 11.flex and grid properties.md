# 1. Parent and Child Properties

Consider:

```html
<div class="container">
    <div class="box">1</div>
    <div class="box">2</div>
    <div class="box">3</div>
</div>
```

The parent can become a layout container:

```css
.container {
    display: flex;
}
```

Think of the structure as:

```text
.container
│
├── .box
├── .box
└── .box
```

The `.container` is the **Flex container**.

The `.box` elements are **Flex items**.

The same parent/child idea applies to Grid.

```text
FLEXBOX
│
├── Properties for the PARENT
│
└── Properties for the CHILD


GRID
│
├── Properties for the PARENT
│
└── Properties for the CHILD
```

This distinction is important because some properties control the **container**, while others control an **individual item**.

---

# 2. Flexbox Properties

Start with:

```css
.container {
    display: flex;
}
```

Now the direct children become Flex items.

Important Flexbox parent properties:

```css
display: flex;

flex-direction:

justify-content:

align-items:

flex-wrap:

gap:
```

Important Flexbox child properties:

```css
flex:

order:

align-self:

flex-grow:

flex-shrink:

flex-basis:
```

For beginners, first master:

```text
display
flex-direction
justify-content
align-items
flex-wrap
gap
```

Then learn the item properties.

# 3. `flex-direction`

`flex-direction` controls the direction of the Flexbox main axis.

## `row`

This is the default:

```css
.container {
    display: flex;
    flex-direction: row;
}
```

Result:

```text
┌───┐ ┌───┐ ┌───┐
│ 1 │ │ 2 │ │ 3 │
└───┘ └───┘ └───┘
       → → →
```

## `row-reverse`

```css
flex-direction: row-reverse;
```

Result:

```text
┌───┐ ┌───┐ ┌───┐
│ 3 │ │ 2 │ │ 1 │
└───┘ └───┘ └───┘
       ← ← ←
```

## `column`

```css
flex-direction: column;
```

Result:

```text
┌───┐
│ 1 │
└───┘
  ↓
┌───┐
│ 2 │
└───┘
  ↓
┌───┐
│ 3 │
└───┘
```

## `column-reverse`

```css
flex-direction: column-reverse;
```

Result:

```text
┌───┐
│ 3 │
└───┘
  ↑
┌───┐
│ 2 │
└───┘
  ↑
┌───┐
│ 1 │
└───┘
```

### Memory

```text
row            → →
row-reverse    ← ←

column         ↓
column-reverse ↑
```

# 4. `justify-content`

`justify-content` controls how Flex items are distributed along the **main axis**.

If:

```css
flex-direction: row;
```

then the main axis is horizontal:

```text
→ → → → →
```

Therefore `justify-content` controls horizontal distribution.

## `flex-start`

```css
justify-content: flex-start;
```

```text
┌───┐ ┌───┐ ┌───┐
│ 1 │ │ 2 │ │ 3 │
└───┘ └───┘ └───┘
```

Items start from the beginning.

## `center`

```css
justify-content: center;
```

```text
       ┌───┐ ┌───┐ ┌───┐
       │ 1 │ │ 2 │ │ 3 │
       └───┘ └───┘ └───┘
```

Items are centered.

## `flex-end`

```css
justify-content: flex-end;
```

```text
                    ┌───┐ ┌───┐ ┌───┐
                    │ 1 │ │ 2 │ │ 3 │
                    └───┘ └───┘ └───┘
```

## `space-between`

```css
justify-content: space-between;
```

```text
┌───┐                    ┌───┐                    ┌───┐
│ 1 │                    │ 2 │                    │ 3 │
└───┘                    └───┘                    └───┘
```

Space is placed between the items, with no extra space at the outer edges.

This is very useful for navigation bars:

```css
.navbar {
    display: flex;
    justify-content: space-between;
}
```

## `space-around`

```css
justify-content: space-around;
```

There is space around each item.

## `space-evenly`

```css
justify-content: space-evenly;
```

The spacing between items and the outer edges is equal.

---

# 5. `align-items`

`align-items` controls alignment along the **cross axis**.

For:

```css
flex-direction: row;
```

the axes are:

```text
              Cross axis
                  ↑
                  │
                  │
Main axis ────────┼────────→
                  │
                  ↓
```

Therefore:

```text
justify-content
    ↓
main axis

align-items
    ↓
cross axis
```

For a row layout, `align-items` usually controls vertical alignment.

## `flex-start`

```css
align-items: flex-start;
```

Items align at the start of the cross axis.

## `center`

```css
align-items: center;
```

Items are vertically centered in a row-based Flex container.

This is very commonly used:

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

## Other useful values

```css
align-items: flex-end;
align-items: stretch;
align-items: baseline;
```

---

# 6. `justify-content` vs `align-items`

For:

```css
flex-direction: row;
```

remember:

```text
              align-items
                   ↑
                   │
                   │
justify-content ───┼────────→
                   │
                   ↓
```

Easy memory:

> **JUSTIFY = main axis**

> **ALIGN = cross axis**

But there is an important detail:

If you change:

```css
flex-direction: column;
```

the axes change.

Therefore, do not permanently memorize:

```text
justify = horizontal
align = vertical
```

Instead remember:

```text
justify-content → main axis
align-items     → cross axis
```

# 7. `flex-wrap`

By default, Flexbox tries to keep items on one line:

```css
flex-wrap: nowrap;
```

Example:

```text
1  2  3  4  5  6  7  8
```

When the container becomes smaller, items may be squeezed.

Use:

```css
flex-wrap: wrap;
```

Then items can move onto additional lines:

```text
1  2  3  4

5  6  7  8
```

Example:

```css
.products {
    display: flex;
    flex-wrap: wrap;
}
```

Useful for:

- Cards
- Tags
- Buttons
- Product lists

# 8. `gap`

Flexbox supports `gap`:

```css
.container {
    display: flex;
    gap: 20px;
}
```

Instead of:

```text
1 2 3
```

you get:

```text
1    2    3
```

You can also control the directions separately:

```css
row-gap: 20px;
column-gap: 30px;
```

# 9. `flex`

`flex` is primarily a **Flex item property**.

Example:

```html
<div class="container">
    <div class="box box1">1</div>
    <div class="box box2">2</div>
    <div class="box box3">3</div>
</div>
```

CSS:

```css
.box1 {
    flex: 2;
}

.box2 {
    flex: 1;
}

.box3 {
    flex: 1;
}
```

The available flexible space is distributed in a ratio of approximately:

```text
Box 1 = 2 parts
Box 2 = 1 part
Box 3 = 1 part
```

Conceptually:

```text
┌──────────────────┬─────────┬─────────┐
│      Box 1       │  Box 2  │  Box 3  │
│       2          │    1    │    1    │
└──────────────────┴─────────┴─────────┘
```

# 10. `flex-grow`, `flex-shrink`, and `flex-basis`

These three properties give you **fine-grained control** over how a Flex item behaves when space is available or limited. They are the building blocks behind the `flex` shorthand.

---

## `flex-basis`

> *"What is my starting size before growing or shrinking?"*

Sets the **initial size** of a Flex item before any space distribution happens.

```css
flex-basis: 200px;   /* starts at 200px */
flex-basis: auto;    /* uses the element's own width/height */
flex-basis: 0;       /* starts from zero */
```

Think of it as a replacement for `width` (in a row layout).

---

## `flex-grow`

> *"How much of the leftover space do I claim?"*

When the container has **extra space**, `flex-grow` decides how to share it.

```css
flex-grow: 0;   /* default — do not grow */
flex-grow: 1;   /* take a share of the extra space */
flex-grow: 2;   /* take twice as much as a sibling with flex-grow: 1 */
```

It is a **ratio**, not a fixed size.

Example:

```text
Container has 300px of extra space

.box1 { flex-grow: 2; }
.box2 { flex-grow: 1; }

┌─────────────────────┬──────────┐
│   box1 (+200px)     │ box2     │
│                     │ (+100px) │
└─────────────────────┴──────────┘

Total ratio = 3 parts
box1 = 2/3 of 300px = 200px extra
box2 = 1/3 of 300px = 100px extra
```

---

## `flex-shrink`

> *"How much do I give up when space is tight?"*

When the container is **too small**, `flex-shrink` decides who shrinks more.

```css
flex-shrink: 1;   /* default — shrink proportionally */
flex-shrink: 0;   /* refuse to shrink (may overflow) */
flex-shrink: 2;   /* shrink twice as fast as siblings */
```

---

## Using all three together — the `flex` shorthand

```css
.item {
  flex: 1 1 200px;
  /*    ↑ ↑  ↑
        │ │  └── flex-basis:  start at 200px
        │ └───── flex-shrink: shrink if needed
        └─────── flex-grow:   grow if space is available  */
}
```

The shorthand `flex: grow shrink basis` is the cleanest way to write all three.

---

## Quick reference

| Property | Question it answers | Default |
|---|---|---|
| `flex-basis` | How big do I *start*? | `auto` |
| `flex-grow` | Do I *expand* if there is extra space? | `0` |
| `flex-shrink` | Do I *compress* if space is tight? | `1` |

---

## Common pattern

```css
.item {
  flex: 1;
}
```

This expands to `flex: 1 1 0` — meaning:

```text
Start from zero      (flex-basis:   0)
Grow with siblings   (flex-grow:    1)
Shrink with siblings (flex-shrink:  1)
```

This is how you create **equal-width columns** in Flexbox.

# 11. `order`

Normally:

```text
1  2  3
```

You can change the visual order:

```css
.box1 {
    order: 3;
}

.box2 {
    order: 1;
}

.box3 {
    order: 2;
}
```

Result:

```text
2  3  1
```

Important:

> `order` changes the visual order, not the HTML source order.

Use it carefully, especially when accessibility and logical reading order matter.

# 12. `align-self`

`align-items` controls all Flex items.

`align-self` can override the alignment of one particular item.

Example:

```css
.container {
    display: flex;
    align-items: center;
}

.box2 {
    align-self: flex-start;
}
```

Mental model:

```text
align-items
    ↓
all items

align-self
    ↓
one specific item
```

# 14. CSS Grid Properties

Grid also has parent/container and child/item properties.

Example:

```html
<div class="gallery">
    <div>1</div>
    <div>2</div>
    <div>3</div>
    <div>4</div>
</div>
```

Parent:

```css
.gallery {
    display: grid;
}
```

---

# 15. `grid-template-columns`

This controls the columns.

```css
grid-template-columns: repeat(3, 1fr);
```

Result:

```text
┌─────────┬─────────┬─────────┐
│    1    │    2    │    3    │
├─────────┼─────────┼─────────┤
│    4    │    5    │    6    │
└─────────┴─────────┴─────────┘
```

You can also explicitly define sizes:

```css
grid-template-columns: 200px 1fr 300px;
```

Meaning:

```text
Column 1 → 200px
Column 2 → remaining flexible space
Column 3 → 300px
```

---

# 16. `grid-template-rows`

Controls row sizes.

```css
grid-template-rows: 200px 100px;
```

Meaning:

```text
Row 1 → 200px
Row 2 → 100px
```

Example:

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: 100px 200px;
}
```

---

# 17. `gap` in Grid

```css
.gallery {
    display: grid;
    gap: 20px;
}
```

You can also use:

```css
row-gap: 20px;
column-gap: 30px;
```

Example:

```text
┌──────┐    ┌──────┐    ┌──────┐
│  1   │    │  2   │    │  3   │
└──────┘    └──────┘    └──────┘

        row/column spacing
```

# 18. `grid-column`

`grid-column` is a **Grid item property**.

Suppose the column lines are:

```text
Column lines:

1       2       3       4
│       │       │       │
```

If you write:

```css
.product1 {
    grid-column: 1 / 3;
}
```

it means:

> Start at grid line 1 and end at grid line 3.

Therefore Product 1 occupies:

```text
Column 1 + Column 2
```

Important:

```css
grid-column: 1 / 3;
```

does **not** mean "column 1 through column 3."

It means:

```text
Start line = 1
End line   = 3
```

---

# 19. `grid-row`

The same concept works vertically.

```css
.product1 {
    grid-row: 1 / 3;
}
```

Means:

```text
Start row line = 1
End row line   = 3
```

Therefore it occupies:

```text
Row 1 + Row 2
```

---

# 20. `span`

Instead of:

```css
grid-column: 1 / 3;
```

you can sometimes use:

```css
grid-column: span 2;
```

Meaning:

> Occupy two columns.

Similarly:

```css
grid-row: span 2;
```

means:

> Occupy two rows.

Example:

```css
.product1 {
    grid-column: span 2;
    grid-row: span 2;
}
```

This is useful when you care about **how many tracks the item should occupy** rather than the exact start/end lines.

---

# 21. `justify-items`

`justify-items` controls the horizontal alignment of Grid items **inside their grid areas**.

```css
.gallery {
    display: grid;
    justify-items: center;
}
```

Conceptually:

```text
Grid cell

┌─────────────────────┐
│         ┌─────┐     │
│         │ BOX │     │
│         └─────┘     │
└─────────────────────┘
```

Useful values:

```css
justify-items: start;
justify-items: center;
justify-items: end;
justify-items: stretch;
```

---

# 22. `align-items` in Grid

Grid also supports:

```css
align-items: center;
```

This controls vertical alignment of items inside their grid areas.

Think:

```text
justify-items
    ↓
horizontal position inside cell

align-items
    ↓
vertical position inside cell
```

---

# 23. `place-items`

If you want both:

```css
justify-items: center;
align-items: center;
```

you can use the shorthand:

```css
place-items: center;
```

So:

```css
.gallery {
    display: grid;
    place-items: center;
}
```

means approximately:

```css
justify-items: center;
align-items: center;
```

---

# 24. `justify-content` in Grid

This is different from `justify-items`.

### `justify-items`

Moves the **items inside their cells**.

### `justify-content`

Moves the **entire Grid inside the container** when there is extra horizontal space.

Conceptually:

```text
Container

┌────────────────────────────────────────────┐
│                                            │
│      [Grid] [Grid] [Grid]                 │
│                                            │
└────────────────────────────────────────────┘
```

You can use:

```css
justify-content: center;
```

Other values include:

```css
start
center
end
space-between
space-around
space-evenly
```

---

# 25. `align-content` in Grid

Similar to `justify-content`, but on the vertical axis.

```css
align-content: center;
```

This moves the **entire Grid vertically** when there is extra space in the container.

---

# 26. `grid-auto-rows`

Grid can automatically create rows.

You can control the size of those automatically created rows:

```css
.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-rows: 200px;
}
```

Meaning:

> Automatically created rows should be 200px high.

---

# 27. `grid-auto-columns`

Similar concept:

```css
grid-auto-columns: 200px;
```

This controls automatically generated columns.

For beginner layouts, `grid-auto-rows` is generally encountered more often.

---

# 28. `grid-auto-flow`

This controls how automatically positioned Grid items flow.

Default:

```css
grid-auto-flow: row;
```

Items normally fill row by row:

```text
1  2  3
4  5  6
7  8  9
```

With:

```css
grid-auto-flow: column;
```

the flow can be column-oriented:

```text
1  4  7
2  5  8
3  6  9
```

For beginner projects, the default `row` behavior is usually sufficient.

---

# 29. `grid-template-areas`

This is useful for larger page layouts.

Imagine:

```text
┌──────────────┬──────────────────────┐
│              │       Header         │
│   Sidebar    ├──────────────────────┤
│              │       Content        │
└──────────────┴──────────────────────┘
```

CSS:

```css
.container {
    display: grid;

    grid-template-columns: 200px 1fr;

    grid-template-areas:
        "sidebar header"
        "sidebar content";
}
```

Then assign each element:

```css
.sidebar {
    grid-area: sidebar;
}

.header {
    grid-area: header;
}

.content {
    grid-area: content;
}
```

This is especially useful for dashboards and larger application layouts.

# 30. Using These Properties in an E-Commerce Project

For the ShopZone-style e-commerce page you are building, think like this:

```text
HEADER
│
└── Flexbox
      │
      ├── justify-content
      ├── align-items
      ├── gap
      └── flex-wrap


HERO
│
└── Grid
      │
      ├── grid-template-columns
      ├── gap
      └── grid-column / grid-row


HERO CONTENT
│
└── Flexbox
      │
      ├── align-items
      ├── justify-content
      └── gap


FEATURES
│
└── Grid
      │
      └── repeat()


PRODUCTS
│
└── Grid
      │
      ├── grid-template-columns
      └── gap


PRODUCT CARD
│
└── Flexbox
      │
      ├── flex-direction
      ├── align-items
      └── gap
```

The important idea is:

> A real website does not have to use only Grid or only Flexbox. Different sections can use the layout system that fits them best.

# 31. What to Learn First

Don't try to memorize every property immediately.

## Level 1 — Master these first

### Flexbox

```css
display: flex;

flex-direction:

justify-content:

align-items:

flex-wrap:

gap:
```

### Grid

```css
display: grid;

grid-template-columns:

grid-template-rows:

gap:

grid-column:

grid-row:
```

These properties are enough to build many real layouts.

---

## Level 2

### Flexbox

```css
flex:

order:

align-self:

flex-grow:

flex-shrink:

flex-basis:
```

### Grid

```css
grid-column: span;

grid-row: span;

justify-items:

align-items:

place-items:

justify-content:

align-content:

grid-auto-rows:

grid-auto-flow:
```

---

## Level 3

Then learn:

```css
grid-template-areas:

grid-area:

auto-fit:

auto-fill:

minmax():
```

For example:

```css
grid-template-columns:
    repeat(auto-fit, minmax(250px, 1fr));
```

This is especially useful for responsive card layouts.

# 32. Complete Mental Model

When you see a layout, ask three questions.

## Question 1

> Is the parent arranging things mainly in one direction?

```text
YES
 ↓
FLEXBOX
```

## Question 2

> Do I need rows AND columns?

```text
YES
 ↓
GRID
```

## Question 3

> Does the layout need to change at smaller widths?

```text
YES
 ↓
MEDIA QUERIES
```

Then choose the relevant properties.

Example:

```text
NAVBAR
  ↓
Flexbox
  ↓
display: flex
  ↓
justify-content
align-items
gap
  ↓
Media query
  ↓
Mobile layout
```

Product gallery:

```text
PRODUCTS
   ↓
Grid
   ↓
grid-template-columns
gap
   ↓
Media query
   ↓
3 columns
   ↓
2 columns
   ↓
1 column
```

# 33. Practice

## Practice 1 — Flexbox

Create:


# Final Memory Tricks

### Flexbox

> **One dimension — Row OR Column**

### Grid

> **Two dimensions — Rows AND Columns**

### `justify-content`

> Main axis

### `align-items`

> Cross axis

### `flex-wrap`

> Allows Flex items to move onto additional lines

### `flex-grow`

> Distributes extra space — ratio based

### `flex-shrink`

> Controls who shrinks when space is tight

### `flex-basis`

> Sets the starting size before grow/shrink kicks in

### `grid-column`

> Controls where a Grid item starts/ends horizontally

### `grid-row`

> Controls where a Grid item starts/ends vertically

### `justify-items`

> Aligns Grid items inside their cells horizontally

### `align-items`

> Aligns Grid items inside their cells vertically

### `justify-content`

> Positions the entire Grid horizontally when there is extra space

### `align-content`

> Positions the entire Grid vertically when there is extra space
