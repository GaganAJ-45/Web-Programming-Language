# 1. What is CSS Grid?

**CSS Grid** is a CSS layout system used to arrange HTML elements in **rows and columns**.

Think about a classroom seating arrangement:

```text
             COLUMNS

          1        2        3
       ┌──────┬────────┬──────┐
Row 1  │  A   │   B    │  C   │
       ├──────┼────────┼──────┤
Row 2  │  D   │   E    │  F   │
       ├──────┼────────┼──────┤
Row 3  │  G   │   H    │  I   │
       └──────┴────────┴──────┘
```

Grid gives us control over both:

* Rows
* Columns

A simple example:

```html
<div class="gallery">
    <div class="product">1</div>
    <div class="product">2</div>
    <div class="product">3</div>
    <div class="product">4</div>
    <div class="product">5</div>
    <div class="product">6</div>
</div>
```

CSS:

```css
.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}
```

Result:

```text
┌─────────┐   ┌─────────┐   ┌─────────┐
│    1    │   │    2    │   │    3    │
└─────────┘   └─────────┘   └─────────┘

┌─────────┐   ┌─────────┐   ┌─────────┐
│    4    │   │    5    │   │    6    │
└─────────┘   └─────────┘   └─────────┘
```

# 2. Grid Container and Grid Items

Consider:

```html
<div class="gallery">
    <div class="product">Product 1</div>
    <div class="product">Product 2</div>
    <div class="product">Product 3</div>
</div>
```

Here:

```text
gallery
   │
   ├── product 1
   ├── product 2
   └── product 3
```

`.gallery` is the **parent**.

`.product` elements are the **children**.

When we write:

```css
.gallery {
    display: grid;
}
```

`.gallery` becomes the **Grid Container**.

Its direct children become **Grid Items**.

```text
.gallery                 → Grid Container
│
├── .product             → Grid Item
├── .product             → Grid Item
└── .product             → Grid Item
```

# 3. Grid Columns

One of the most important Grid properties is:

```css
grid-template-columns
```

It tells the browser:

> How many columns should this grid have, and how wide should they be?

## One column

```css
.gallery {
    display: grid;
    grid-template-columns: 300px;
}
```

Result:

```text
┌──────────────┐
│      1       │
├──────────────┤
│      2       │
├──────────────┤
│      3       │
└──────────────┘
```

## Two columns

```css
grid-template-columns: 300px 300px;
```

Result:

```text
┌──────────┐  ┌──────────┐
│    1     │  │    2     │
└──────────┘  └──────────┘

┌──────────┐  ┌──────────┐
│    3     │  │    4     │
└──────────┘  └──────────┘
```

## Three columns

```css
grid-template-columns: 200px 200px 200px;
```

Result:

```text
┌───────┐ ┌───────┐ ┌───────┐
│   1   │ │   2   │ │   3   │
└───────┘ └───────┘ └───────┘

┌───────┐ ┌───────┐ ┌───────┐
│   4   │ │   5   │ │   6   │
└───────┘ └───────┘ └───────┘
```

### Simple rule

```text
Number of values = Number of columns
```

For example:

```css
grid-template-columns: 100px 100px;
```

means 2 columns.

```css
grid-template-columns: 100px 100px 100px;
```

means 3 columns.

# 4. The `fr` Unit

Instead of using fixed widths like:

```css
grid-template-columns: 300px 300px 300px;
```

CSS Grid provides the `fr` unit.

`fr` means:

> Fraction of the available space.

Example:

```css
.gallery {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
}
```

This divides the available space into **3 equal parts**.

```text
Available Container Width

┌────────────┬────────────┬────────────┐
│    1fr     │    1fr     │    1fr     │
└────────────┴────────────┴────────────┘

     1/3          1/3          1/3
```

We can also use different fractions:

```css
grid-template-columns: 1fr 2fr;
```

There are three total fractions.

```text
┌────────────┬─────────────────────────┐
│    1fr     │           2fr           │
└────────────┴─────────────────────────┘

     1/3                 2/3
```

This is useful for layouts such as:

```text
┌────────────┬──────────────────────────────┐
│            │                              │
│  SIDEBAR   │         MAIN CONTENT         │
│            │                              │
└────────────┴──────────────────────────────┘
     1fr                    3fr
```

CSS:

```css
.container {
    display: grid;
    grid-template-columns: 1fr 3fr;
}
```

---

# 5. The `repeat()` Function

Instead of writing:

```css
grid-template-columns: 1fr 1fr 1fr;
```

we can write:

```css
grid-template-columns: repeat(3, 1fr);
```

Both mean exactly the same thing.

```text
repeat(3, 1fr)

        ↓

1fr 1fr 1fr
```

Examples:

```css
repeat(2, 1fr)
```

means:

```text
1fr 1fr
```

And:

```css
repeat(4, 1fr)
```

means:

```text
1fr 1fr 1fr 1fr
```

Therefore:

```css
grid-template-columns: repeat(4, 1fr);
```

creates four equal columns.

---

# 6. Grid Rows

Columns are controlled using:

```css
grid-template-columns
```

Rows can be controlled using:

```css
grid-template-rows
```

Example:

```css
.container {
    display: grid;

    grid-template-columns: repeat(3, 1fr);

    grid-template-rows: 100px 200px;
}
```

Result:

```text
             COLUMNS

           1       2       3

       ┌───────┬───────┬───────┐
100px  │   1   │   2   │   3   │
       ├───────┼───────┼───────┤
200px  │   4   │   5   │   6   │
       └───────┴───────┴───────┘
```

In many normal card layouts, you don't need to manually create rows. Grid can automatically create additional rows when required.

# 7. The `gap` Property

Suppose the elements are touching:

```text
┌──────┐┌──────┐┌──────┐
│  1   ││  2   ││  3   │
└──────┘└──────┘└──────┘
```

Use:

```css
gap: 20px;
```

Example:

```css
.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}
```

Result:

```text
┌──────┐    ┌──────┐    ┌──────┐
│  1   │    │  2   │    │  3   │
└──────┘    └──────┘    └──────┘
        ← gap →
```

We can also separately control:

```css
row-gap: 20px;
column-gap: 30px;
```

# 8. Flexbox vs Grid

This is one of the most important concepts.

## Flexbox

Flexbox primarily works in **one dimension**.

That means:

```text
ROW
→ → → → →
```

or:

```text
COLUMN
↓
↓
↓
↓
```

Example:

```css
.container {
    display: flex;
}
```

Default direction:

```text
Item 1    Item 2    Item 3    Item 4
────────────────────────────────────→
```

Or:

```css
.container {
    display: flex;
    flex-direction: column;
}
```

Result:

```text
Item 1
  ↓
Item 2
  ↓
Item 3
  ↓
Item 4
```

## Grid

Grid is designed for **two-dimensional layouts**.

It works with:

```text
Rows + Columns
```

Example:

```text
           COLUMN 1    COLUMN 2    COLUMN 3

ROW 1        Card         Card         Card

ROW 2        Card         Card         Card

ROW 3        Card         Card         Card
```

### Main difference

```text
FLEXBOX
   ↓
One-dimensional
   ↓
Row OR Column


GRID
   ↓
Two-dimensional
   ↓
Rows AND Columns
```

---

# Flexbox vs Grid Comparison Table

| Feature              | Flexbox       | Grid             |
| -------------------- | ------------- | ---------------- |
| Dimension            | Mainly 1D     | 2D               |
| Direction            | Row OR Column | Rows AND Columns |
| Navbar               | Excellent     | Possible         |
| Buttons              | Excellent     | Possible         |
| Centering            | Excellent     | Excellent        |
| Card collection      | Good          | Excellent        |
| Image gallery        | Possible      | Excellent        |
| Dashboard            | Possible      | Excellent        |
| Complex page layouts | Harder        | Easier           |
| Responsive design    | Yes           | Yes              |

> **Important:** Grid does not replace Flexbox. Modern websites commonly use both.

# 9. When to Use Flexbox

Flexbox is excellent for arranging elements mainly in one direction.

## Navbar

```text
┌──────────────────────────────────────────────┐
│ LOGO             Home About Projects Contact│
└──────────────────────────────────────────────┘
```

CSS:

```css
nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
```

## Buttons

```text
Cancel                         Submit
```

## Icon + Text

```text
☎ Contact Us
```

## Centering content

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

Remember:

```text
Flexbox → excellent for alignment in one direction
```

```text
┌─────────┐ ┌─────────┐ ┌─────────┐
```

## Gallery

```text
Image     Image     Image

Image     Image     Image
```

## Dashboard

```text

│            ├─────────────┬─────────────┤
```

# 11. Using Grid and Flexbox Together

In real websites, we commonly use both.

Consider a product section:

```text
PRODUCT SECTION                  ← GRID

┌─────────────────┐
│     IMAGE       │
│                 │
│ Cappuccino      │
│                 │
│ $4       Order  │              ← FLEX
└─────────────────┘
```

The overall product collection could use Grid:

```css
.products {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}
```

Inside each card:

```html
<div class="product-card">

    <img src="coffee.jpg">

    <h2>Cappuccino</h2>

    <div class="product-bottom">
        <p>$4</p>
        <button>Order</button>
    </div>

</div>
```

Use Flexbox for the price and button:

```css
.product-bottom {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
```

Mental model:

```text
GRID
│
├── Product Card
│      │
│      └── FLEX
│          ├── Price
│          └── Button
│
├── Product Card
│      │
│      └── FLEX
│
└── Product Card
       │
       └── FLEX
```

So don't think:

```text
Grid OR Flexbox
```

Think:

```text
Which layout system is best for this particular section?
```

**Responsive Web Design** means designing a website so that it adapts properly to different viewport sizes.

For example:

## Desktop

```text

├───────────────────────────────────────────┤
│                                           │
│               HERO SECTION                │

├───────────────────────────────────────────┤
│    Card 1       Card 2       Card 3       │
```

## Tablet

```text
┌──────────────────────────────┐
│ LOGO     Home About Contact  │
├──────────────────────────────┤
│         HERO SECTION         │
├──────────────────────────────┤
│    Card 1      Card 2        │
```

## Mobile

```text
┌─────────────────┐
```

# 13. Media Queries

A **media query** allows CSS rules to apply only when certain conditions are true.

Basic syntax:

```css
@media (max-width: 768px) {

    /* CSS */

}
```

This means:

> Apply this CSS when the viewport width is 768px or smaller.

Example:

```css
body {
    background-color: white;
}

@media (max-width: 600px) {

    body {
        background-color: lightblue;
    }

}
```

Result:

```text
Viewport > 600px
       ↓
background = white


Viewport <= 600px
       ↓
background = lightblue
```

---

# 14. `max-width` Explained

This is extremely important.

Consider:

```css
@media (max-width: 768px)
```

It means:

```text
viewport width <= 768px
```

It does **NOT** mean:

```text
Only tablets
```

It means:

> Every viewport that is 768px or smaller.

Therefore:

```text
1200px    ❌
1000px    ❌
800px     ❌
768px     ✅
700px     ✅
600px     ✅
500px     ✅
426px     ✅
400px     ✅
300px     ✅
```

So a mobile screen such as `400px` also satisfies:

```css
@media (max-width: 768px)
```

because:

```text
400 <= 768

TRUE ✅
```

---

# Understanding Multiple `max-width` Media Queries

Consider:

```css
@media (max-width: 1440px) {

    .gallery {
        grid-template-columns: repeat(3, 1fr);
    }

}

@media (max-width: 768px) {

    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }

}

@media (max-width: 426px) {

    .gallery {
        grid-template-columns: 1fr;
    }

}
```

## Screen = 1200px

Browser checks:

```text
1200 <= 1440   ✅
1200 <= 768    ❌
1200 <= 426    ❌
```

Therefore:

```text
3 columns
```

---

## Screen = 700px

Browser checks:

```text
700 <= 1440   ✅
700 <= 768    ✅
700 <= 426    ❌
```

Both the `1440px` and `768px` rules match.

CSS reads from top to bottom.

First:

```text
1440 rule
    ↓
3 columns
```

Then:

```text
768 rule
    ↓
2 columns
```

Since the `768px` rule comes later and has the same selector specificity, it overrides the earlier `grid-template-columns`.

Final result:

```text
2 columns
```

---

## Screen = 400px

This is the most important example.

Browser checks:

```text
400 <= 1440   ✅

400 <= 768    ✅

400 <= 426    ✅
```

All three media queries match.

CSS processes them in source order:

```text
START
  │
  ▼
max-width: 1440px
  │
  │ TRUE
  ▼
3 columns
  │
  ▼
max-width: 768px
  │
  │ TRUE
  ▼
2 columns
  │
  ▼
max-width: 426px
  │
  │ TRUE
  ▼
1 column
  │
  ▼
FINAL RESULT
```

Therefore:

```text
400px viewport
       ↓
1 column
```

---

# Very Important Concept: CSS Cascade

At `400px`, all three rules are active.

```text
┌─────────────────────────┬─────────┐
│ Media Query             │ 400px   │
├─────────────────────────┼─────────┤
│ max-width: 1440px       │ TRUE ✅ │
│ max-width: 768px        │ TRUE ✅ │
│ max-width: 426px        │ TRUE ✅ │
└─────────────────────────┴─────────┘
```

They all modify:

```css
grid-template-columns
```

When rules have the same specificity, the later matching declaration wins.

Therefore:

```text
3 columns
    ↓
overwritten
    ↓
2 columns
    ↓
overwritten
    ↓
1 column

FINAL = 1 column
```

# 15. `min-width` Explained

`min-width` works in the opposite direction.

```css
@media (min-width: 768px)
```

means:

```text
viewport width >= 768px
```

Examples:

```text
400px     ❌
600px     ❌
767px     ❌
768px     ✅
900px     ✅
1200px    ✅
1440px    ✅
```

Comparison:

```text
max-width: 768px
        ↓
width <= 768


min-width: 768px
        ↓
width >= 768
```

Easy way to remember:

```text
MAX = maximum allowed width

MIN = minimum required width
```

# 16. Why Media Query Order Matters

Suppose we incorrectly write:

```css
@media (max-width: 426px) {

    .gallery {
        grid-template-columns: 1fr;
    }

}

@media (max-width: 768px) {

    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }

}

@media (max-width: 1440px) {

    .gallery {
        grid-template-columns: repeat(3, 1fr);
    }

}
```

Now suppose:

```text
Viewport = 400px
```

All three conditions are true.

CSS reads:

```text
426px
  ↓
1 column
  ↓
  ↓ overwritten

768px
  ↓
2 columns
  ↓
  ↓ overwritten

1440px
  ↓
3 columns
  ↓
FINAL
```

Therefore mobile incorrectly gets:

```text
3 columns
```

This happens because the `1440px` rule appears last.

---

# Correct Order with `max-width`

For a desktop-first approach, generally go from larger breakpoints to smaller breakpoints.

```css
@media (max-width: 1440px) {

}

@media (max-width: 768px) {

}

@media (max-width: 426px) {

}
```

Think:

```text
LARGE
  ↓
MEDIUM
  ↓
SMALL
```

Or:

```text
Desktop
   ↓
Tablet
   ↓
Mobile
```

# 17. Correct Desktop-First Approach

Usually, we don't need a media query for the normal desktop layout.

Write the desktop layout as the default:

```css
.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}
```

Then tablet:

```css
@media (max-width: 768px) {

    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }

}
```

Then mobile:

```css
@media (max-width: 426px) {

    .gallery {
        grid-template-columns: 1fr;
    }

}
```

Complete:

```css
.gallery {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}


/* Tablet */

@media (max-width: 768px) {

    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }

}


/* Mobile */

@media (max-width: 426px) {

    .gallery {
        grid-template-columns: 1fr;
    }

}
```

Visual representation:

```text
DESKTOP
> 768px

┌──────┐ ┌──────┐ ┌──────┐
│  1   │ │  2   │ │  3   │
└──────┘ └──────┘ └──────┘


TABLET
427px — 768px

┌──────────┐ ┌──────────┐
│    1     │ │    2     │
└──────────┘ └──────────┘

┌──────────┐ ┌──────────┐
│    3     │ │    4     │
└──────────┘ └──────────┘


MOBILE
<= 426px

┌────────────────────┐
│         1          │
└────────────────────┘

┌────────────────────┐
│         2          │
└────────────────────┘

┌────────────────────┐
│         3          │
└────────────────────┘
```

# Do Not Repeat Unchanged CSS

You do NOT need this:

```css
@media (max-width: 768px) {

    .gallery {
        border: 2px solid black;
        display: grid;
        grid-template-columns: repeat(2, 1fr);
        gap: 20px;
    }

}
```

if those properties are already defined above.

For example:

```css
.gallery {
    border: 2px solid black;
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}
```

Inside the media query, only change what needs to change:

```css
@media (max-width: 768px) {

    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }

}
```

The other properties remain active.

# 18. Mobile-First Approach

Another common approach is **mobile-first design**.

Instead of starting with desktop, start with mobile.

Default:

```css
.gallery {
    display: grid;
    grid-template-columns: 1fr;
    gap: 20px;
}
```

Tablet:

```css
@media (min-width: 600px) {

    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }

}
```

Desktop:

```css
@media (min-width: 1000px) {

    .gallery {
        grid-template-columns: repeat(3, 1fr);
    }

}
```

Visual:

```text
MOBILE
1 column
    ↓
TABLET
2 columns
    ↓
DESKTOP
3 columns
```

With mobile-first CSS, the breakpoints generally progress from smaller to larger because we are using `min-width`.

```text
min-width

SMALL → MEDIUM → LARGE
```

With desktop-first CSS using `max-width`:

```text
max-width

LARGE → MEDIUM → SMALL
```

# 20. Responsive Flexbox Example

Suppose we have a hero section.

Desktop:

```text
┌─────────────────┐   ┌─────────────────┐
│                 │   │                 │
│      TEXT       │   │      IMAGE      │
│                 │   │                 │
└─────────────────┘   └─────────────────┘
```

CSS:

```css
.hero {
    display: flex;
    align-items: center;
    gap: 40px;
}
```

By default:

```css
flex-direction: row;
```

For mobile:

```css
@media (max-width: 600px) {

    .hero {
        flex-direction: column;
    }

}
```

Result:

```text
┌─────────────────┐
│                 │
│      TEXT       │
│                 │
└─────────────────┘
         ↓
┌─────────────────┐
│                 │
│      IMAGE      │
│                 │
└─────────────────┘
```

So media queries can modify both Grid and Flexbox layouts.

# 21. `auto-fit` and `minmax()`

After understanding basic Grid, another useful responsive Grid technique is:

```css
.products {
    display: grid;

    grid-template-columns:
        repeat(auto-fit, minmax(250px, 1fr));

    gap: 20px;
}
```

Basic meaning:

> Create as many columns as can fit while keeping each column at least around 250px wide, and allow the columns to grow to fill available space.

On a large screen:

```text
[ CARD ] [ CARD ] [ CARD ] [ CARD ]
```

Medium screen:

```text
[ CARD ] [ CARD ]

[ CARD ] [ CARD ]
```

Small screen:

```text
[       CARD       ]

[       CARD       ]

[       CARD       ]
```

This can sometimes reduce the number of media queries required for a simple card grid.

Learn this after becoming comfortable with:

```css
display: grid;

grid-template-columns:

fr

repeat()

gap
```

## Responsive Design

Responsive design means:

> The website adapts its layout to different viewport sizes.

Example:

```text
Desktop      Tablet       Mobile

3 columns → 2 columns → 1 column
```

---

## Media Query

Example:

```css
@media (max-width: 768px) {

}
```

means:

```text
Apply when viewport width <= 768px
```

It does **not** mean "tablet only."

---

## `max-width`

```css
@media (max-width: 768px)
```

means:

```text
0px -------------------------- 768px
              ✅
```

Everything at or below 768px matches.

---

## `min-width`

```css
@media (min-width: 768px)
```

means:

```text
768px ------------------------------→
                 ✅
```

Everything at or above 768px matches.

---

# Most Important Media Query Rule

For desktop-first CSS using `max-width`:

```css
/* Default Desktop */
.gallery {
    grid-template-columns: repeat(3, 1fr);
}


/* Tablet */
@media (max-width: 768px) {

    .gallery {
        grid-template-columns: repeat(2, 1fr);
    }

}


/* Mobile */
@media (max-width: 426px) {

    .gallery {
        grid-template-columns: 1fr;
    }

}
```

Remember:

```text
MAX-WIDTH

Large
  ↓
Medium
  ↓
Small
```

For mobile-first CSS using `min-width`:

```text
MIN-WIDTH

Small
  ↓
Medium
  ↓
Large
```

## One-Line Memory Tricks

**Flexbox**

> Row **OR** Column.

**Grid**

> Rows **AND** Columns.

**Responsive Design**

> Make the layout adapt to available screen space.

**`max-width: 768px`**

> Apply at **768px and below**.

**`min-width: 768px`**

> Apply at **768px and above**.

**Desktop-first + `max-width`**

> Larger breakpoints → smaller breakpoints.

**Mobile-first + `min-width`**

> Smaller breakpoints → larger breakpoints.
