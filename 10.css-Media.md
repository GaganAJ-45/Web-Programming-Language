# CSS `@media` vs `@media screen`

## Introduction

Responsive websites need to display correctly on different devices such as desktops, laptops, tablets, and mobile phones. CSS provides **Media Queries** to apply different styles depending on the device or screen size.

Many beginners are confused by these two syntaxes:

```css
@media (max-width: 768px) {

}
```

and

```css
@media screen and (max-width: 768px) {

}
```

Although they look different, they are very similar. Let's understand the difference in detail.

---

# What is `@media`?

`@media` is a **CSS at-rule** that allows you to apply styles only when certain conditions are true.

General Syntax:

```css
@media (condition) {

    /* CSS */

}
```

Example:

```css
@media (max-width: 768px) {

    body {
        background-color: lightblue;
    }

}
```

Meaning:

> Apply the CSS when the viewport width is **768px or smaller**.

---

# What is `screen`?

`screen` is called a **Media Type**.

It tells the browser:

> Apply this CSS only when the webpage is displayed on a screen.

Examples of screen devices:

* Desktop Computer
* Laptop
* Tablet
* Mobile Phone
* Smart TV

All of these are considered **screen** devices.

---

# Syntax of `@media screen`

```css
@media screen and (max-width: 768px) {

    body {
        background-color: lightblue;
    }

}
```

This means:

> Apply this CSS only if:

* The current media type is **screen**
* AND the viewport width is **768px or less**

---

# Understanding the Difference

## Using only `@media`

```css
@media (max-width:768px){

}
```

Browser thinks:

```text
Current device = Screen

Width <= 768px ?

YES

Apply CSS
```

---

## Using `@media screen`

```css
@media screen and (max-width:768px){

}
```

Browser thinks:

```text
Current device = Screen ?

YES

AND

Width <=768px ?

YES

Apply CSS
```

---

# Browser Decision Process

Imagine you are using a laptop with a screen width of **700px**.

```text
Current Device

↓

Laptop

↓

Media Type = Screen

↓

Width = 700px

↓

700 <= 768

↓

TRUE

↓

CSS Applied
```

---

Now imagine you press **Ctrl + P** to print the webpage.

```text
Current Device

↓

Printer

↓

Media Type = Print

↓

Is media type Screen?

↓

NO

↓

CSS Not Applied
```

This is why `screen` exists.

# Common Media Types

CSS supports different media types.

| Media Type | Description                     |
| ---------- | ------------------------------- |
| `screen`   | Desktop, Laptop, Tablet, Mobile |
| `print`    | Printed pages and Print Preview |
| `speech`   | Screen readers                  |
| `all`      | All media types                 |

# Example 1 – Screen

```css
@media screen {

    body{
        background:lightblue;
    }

}
```

Applies only on screen devices.

---

# Example 2 – Print

```css
@media print{

    body{
        color:black;
        background:white;
    }

}
```

When printing the webpage:

* White background
* Black text

This makes printed documents easier to read.

Suppose your webpage contains advertisements.

```text

```

Advertisement disappears.

# Why Most Developers Don't Write `screen`

Modern websites are viewed almost entirely on:

* Desktop
* Laptop
* Tablet
* Mobile

All of these are **screen** devices.

Therefore developers usually write:

```css
@media (max-width:768px){

}
```

instead of

```css
@media screen and (max-width:768px){

}
```

Both produce the same result during normal web browsing.

# When Should You Use `@media`?

Use it for responsive websites.

Example:

```css
@media (max-width:768px){

.navbar{

flex-direction:column;

}

}
```

Use Cases:

* Responsive navigation
* Responsive Grid
* Responsive Flexbox
* Mobile layouts
* Tablet layouts

---

# When Should You Use `@media screen`?

Use it when you specifically want your CSS to work **only on screens**.

Example:

```css
@media screen and (max-width:768px){

.gallery{

grid-template-columns:1fr;

}

}
```

This CSS will not apply while printing.

---

# When Should You Use `@media print`?

Use it when printing requires a different layout.

Example:

```css
@media print{

nav,
footer,
.ads{

display:none;

}

}
```

This removes unnecessary content from printed pages.

---

# Which One Should Beginners Use?

If you're building:

* Portfolio Website
* Netflix Clone
* Restaurant Website
* Dashboard
* Gallery
* Landing Page

Use:

```css
@media (max-width:768px){

}
```

This is the most common approach used in modern responsive web development.

---

# Interview Question

### Q. What is the difference between `@media` and `@media screen`?

**Answer:**

* `@media` is the CSS rule used to apply styles based on media conditions.
* `screen` is a media type used inside the `@media` rule.
* `@media (max-width:768px)` checks only the viewport condition.
* `@media screen and (max-width:768px)` checks both the media type (**screen**) and the viewport condition.
* In modern web development, both usually behave the same because websites are normally viewed on screen devices.

---

# Best Practice

For responsive websites, use:

```css
@media (max-width:768px){

}
```

For print-specific styles, use:

```css
@media print{

}
```

Only use:

```css
@media screen and (max-width:768px){

}
```

when you explicitly want those styles to apply **only** on screen devices.
